# easeTrack

Monorepo starter for the Laravel backend and the Python screenshot client.

## Layout

- `laravel/` - backend API, admin panel, models, and migrations
- `python-client/` - desktop screenshot agent

## Current scope

This first pass focuses on the core foundation:

- device registration data model
- screenshot storage model
- settings API
- secure upload flow
- basic Python capture and upload loop

Future updates can add:

- admin auth and dashboard pages
- richer filtering and pagination
- tray icon and Windows startup integration
- reporting and analytics
